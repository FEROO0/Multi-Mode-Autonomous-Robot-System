# Automatic Parking Robot Using ATmega32A

## 📌 Project Overview

This project is an automatic parking robot based on the **ATmega32A microcontroller**. The robot uses **ultrasonic sensors** to detect obstacles and measure distances, then controls its movement to perform an automatic parking process.

## 🎯 Objectives

- Detect obstacles using ultrasonic sensors.
- Measure the distance between the robot and surrounding obstacles.
- Control the robot's movement automatically.
- Implement an automatic parking mechanism.
- Integrate sensors, motors, and the microcontroller into one system.

## 🛠️ Technologies & Components

### Hardware
- ATmega32A Microcontroller
- Ultrasonic Sensors
- DC Geared Motors
- Motor Driver
- Robot Chassis
- Power Supply

### Software
- C Programming
- CodeVisionAVR
- Proteus *(if used for simulation)*

## ⚙️ How It Works

The ultrasonic sensors continuously measure the distance between the robot and nearby obstacles. The ATmega32A processes the sensor readings and determines the appropriate movement of the robot.

Based on the detected obstacles, the microcontroller sends control signals to the motor driver to control the motors and perform the required parking movement.

## 🔧 Main Features

- Automatic obstacle detection
- Distance measurement
- Automatic movement control
- Motor control using ATmega32A
- Embedded system integration
